Open the LHC urgent list, select all the text on the page, copy it, and paste it here. Everything is matched on this phone — nothing is uploaded.
Keywords to watch
Your name as it is printed in the cause list, party names, case numbers. Matching ignores case, spacing and punctuation, so Ahmad Raza also finds RAZA, AHMAD. Add a second spelling if yours varies.
Everything lives in this browser's storage on this phone. Clearing Chrome's site data would erase it — export a backup every so often.

Install on your home screen
Chrome menu (⋮) → Add to Home screen. It then opens like an app and works with no internet. Nothing is sent anywhere.
What this web version cannot do
A browser is not allowed to read another website's pages in the background, so this cannot check the LHC site by itself at 6:30pm — that is why you paste the list in. The Android APK does that part automatically.

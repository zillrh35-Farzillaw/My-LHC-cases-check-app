Check a cause list
Open the LHC urgent list, select all the text on the page, copy it, and paste it here. Everything is matched on this phone — nothing is uploaded.
Search checked lists
Look up any name, judge, serial number or case number across every cause list you've already scanned — even if it isn't one of your keywords.
Check pending files automatically
When on, every pending file below is checked against each cause list you scan. Turn this off to pause fuzzy-matching for the whole list at once — for example while you're cleaning it up — without deleting anything.
Add a pending file
A case whose file you already hold but that has not been fixed (listed) yet. Once added, it is checked on every scan using fuzzy name matching — so spelling or ordering differences in the court's printing won't cause it to be missed. When it appears, you'll be asked to approve the match before it moves into your fixed-cases report.
Case number (optional) — add it once the file has been registered, even before it's fixed. Matching then also catches the exact case number, alongside the usual fuzzy name match.
Keywords to watch
Your name as it is printed in the cause list, party names, case numbers. Matching ignores case, spacing and punctuation, so Ahmad Raza also finds RAZA, AHMAD. Add a second spelling if yours varies. NADRA, National Database, Identity Card and Citizenship are watched by default — they're locked on since these matters must always be flagged.
Add a task
Something a senior or officer told you to do, with a deadline — so it never slips through. You'll see an overdue/due-soon warning here whenever you open the app; the Android app can also alert you at the deadline even if it's closed.
Everything lives in this browser's storage on this phone. Clearing Chrome's site data would erase it — export a backup every so often.
Backup
Downloads a single JSON file with every case, hearing and keyword.
Install on your home screen
Chrome menu (⋮) → Add to Home screen. It then opens like an app and works with no internet. Nothing is sent anywhere.
What this web version cannot do
A browser is not allowed to read another website's pages in the background, so this cannot check the LHC site by itself at 6:30pm — that is why you paste the list in. The Android APK does that part automatically.
